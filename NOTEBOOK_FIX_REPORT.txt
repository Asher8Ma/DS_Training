ERROR #1: AxisError in Cell 163 (Exercise #26)
─────────────────────────────────────────────────────────────────────────────
Description:
  "axis 3 is out of bounds for array of dimension 0"

Root Cause:
  The notebook imports `from numpy import *`, which overwrites Python's
  built-in max() and min() functions with NumPy's versions. When the code
  called max() and min() with scalar arguments, NumPy tried to interpret
  them as array operations and failed.

Original Code (Line 163):
  ```
  R = Z[max(0, pos[0]-shape[0]//2):min(Z.shape[0], pos[0]+shape[0]//2+1),
        max(0, pos[1]-shape[1]//2):min(Z.shape[1], pos[1]+shape[1]//2+1)]
  ```

Fixed Code (Optimized with NumPy idioms):
  ```
  # Use np.clip for boundary management - more NumPy-idiomatic and efficient
  half_shape = (shape[0] // 2, shape[1] // 2)
  start = np.array([pos[0] - half_shape[0], pos[1] - half_shape[1]])
  end = np.array([pos[0] + half_shape[0] + 1, pos[1] + half_shape[1] + 1])
  
  # Clip indices to array bounds
  start = np.clip(start, 0, np.array(Z.shape))
  end = np.clip(end, 0, np.array(Z.shape))
  
  R = Z[start[0]:end[0], start[1]:end[1]]
  ```

Benefits of the Fix:
  ✓ Resolves namespace collision between NumPy and Python built-ins

  ✓ More efficient boundary management
